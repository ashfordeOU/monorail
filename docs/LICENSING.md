## What the FSL means in practice

**Free for you.** Anyone can download, use, read, build and change Monorail, at home or at work,
for free. Companies can roll it out to all their staff.

**Not free to resell.** You may not use the code for a *competing use*: selling Monorail or a
derivative, or offering it as a product or service that substitutes for Monorail. This is what
stops someone copying the repository and selling it as their own app.

**Becomes Apache 2.0 after two years.** On the second anniversary of each release, that version's
code is also available under the Apache License 2.0, with no competing-use restriction.

**Names and icon are separate.** The licence covers code, not branding. See
[TRADEMARKS.md](../TRADEMARKS.md).

## Why we changed from the AGPL

The AGPL allows anyone to sell Monorail as long as they publish their changes. The FSL keeps the
code public and free to use while protecting the project from straight resale. All of Monorail's
code is copyright Ashforde OÜ, which allows this change for new versions. Releases already
published under the AGPL stay available under it.

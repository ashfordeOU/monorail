## About

Monorail by Ashforde® is a scrolling window manager for macOS. Most tiling window managers shrink every
window when a new one opens. Monorail puts each window on a slide in a horizontal strip that runs past
the edges of the screen: a new window slides in beside the one you're using, and nothing else changes
size. Moving focus glides the strip along.

Windows can be dragged onto each other to dock side by side or form tab groups across any apps, nested
as deep as you like. Saved views return the screen to an arrangement with one shortcut, and back and
forward work like a browser. Plain-language commands such as “Slack and Mail side by side” are
understood on the Mac, and Monorail chimes when an AI coding agent in a terminal is waiting for
approval. It imports AeroSpace, yabai and Rectangle setups.

Monorail is native Swift, free with no paid tier.

## Highlights

- **Scrolling strip:** windows never shrink to make room; the strip scrolls instead.
- **Dock anything:** drag a window onto another's edge to split, or its middle to tab, across apps.
- **Saved views** (⌃⌥⌘1–9) with back and forward through where you've been.
- **Say it:** a command palette that understands sentences, processed on the Mac.
- **AI agent alerts:** a chime when your AI coding assistant needs you.
- **Switch in a minute:** imports AeroSpace, yabai/skhd and Rectangle configurations.
- **Battery manager built in:** charge, time left, watts, history and health; every app and AI agent by battery use, with Quit, Pause or Hide; ⚡ marks hungry windows.
- **Every kind of display:** portrait monitors stack windows, screen edges can be kept clear, and Stage Manager pauses it.
- **27 themes**, safe screen sharing, presentation tools and a scripting API.

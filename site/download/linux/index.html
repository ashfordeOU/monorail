Finding the newest beta…

Monorail for GNOME 45 or later, on Wayland and X11. Beta.

  1. In a terminal, in the folder you downloaded to: gnome-extensions install monorail@ashforde.org.shell-extension.zip
  2. Log out and back in (on Wayland GNOME only loads new extensions at login).
  3. Turn it on: gnome-extensions enable monorail@ashforde.org, or in the Extensions app.

If it doesn't start, try again or write to contact@ashforde.org. Found something odd? Tell us.
